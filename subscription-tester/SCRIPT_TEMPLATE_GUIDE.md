# Imagine Studio script template

Download `SCRIPT_TEMPLATE.txt` from the Script page or Upload script window.

1. Replace every bracketed placeholder with your own writing.
2. Use one heading per scene: `SCENE 1 — INT. LIVING ROOM — DAY`. Use `EXT.` for an exterior and `INT.` for an interior. Number subsequent scenes in order.
3. Put action in separate paragraphs. Put a character's name on its own uppercase line, followed by that character's dialogue. Replace the entire bracketed character-name placeholder, including the brackets.
4. Add or remove scene blocks as needed. Match character and location names to your Series Bible.
5. Save as UTF-8 `.txt` and upload it, or paste its text into Imagine Studio.

Start the uploaded file directly with the first scene heading. The current importer can treat content before that heading as a separate “Opening notes” scene. Keep the episode title, premise, total duration, visual style and continuity notes in the corresponding Storybook fields instead. Do not add a second standalone `INT.` or `EXT.` heading under a `SCENE` heading; that can split one intended scene into two.

Importing preserves the script's wording. AI comparison with saved details is optional. This template helps the importer recognize scene boundaries; it does not guarantee that a later AI production plan will pass validation.
