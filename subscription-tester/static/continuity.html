Continuity check

Compare a shot's first and last frames. People and moving things are expected to change; fixed things (set, furniture, props, the camera) must not. Draw a box around each fixed object on the first frame, then run the check. Each box passes when its object is found in the same place and at the same size, within the tolerances, and still matches. Draw each box around the whole object, edges included.
